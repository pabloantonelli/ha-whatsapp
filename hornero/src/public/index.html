Who may trigger automations

Recent senders

Whoever wrote to you lately. Use Allow here rather than typing an ID by hand — WhatsApp often identifies people by a code that looks nothing like their phone number.

Add manually

Incoming messages are sent to Home Assistant as hornero_message events, and automations act on them. While this list is empty, anyone who writes to you can trigger them. Add a group to accept everything posted in it, or a person to accept them anywhere, groups included.

Behaviour

Saved here, not in the add-on options: changes apply immediately unless noted. The add-on options only provide the initial values.

Use the Snippet builder tab to fill these in and copy them, rather than writing them from memory.

Events

hornero_message
A message arrived
hornero_message_ack
A sent message was delivered or read
hornero_presence
A contact came online or is typing

Addressing

People are addressed by phone number with country code and no + (for example 34600000000). Groups need their ID, which cannot be derived from a number — copy it from the Groups & contacts tab.

Node-RED

No token needed: use a call service node for the services above, and an events: all node for the events. The snippet builder writes both out.
