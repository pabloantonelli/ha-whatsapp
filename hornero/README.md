# Home Assistant Add-on: Hornero

WhatsApp messaging for Home Assistant, powered by
[Baileys](https://github.com/WhiskeySockets/Baileys).

Pair your phone from the sidebar panel — by QR code or an 8-digit code — then
send and receive messages from any automation. Each account shows up as a
device with connection sensors, the pairing QR as an image, and buttons.

**Highlights**

- Camera snapshots and video clips straight from a `camera` entity, including
  the seconds recorded before the trigger.
- Incoming messages as Home Assistant events, with an allowlist so only the
  senders you choose can trigger automations.
- Ready-made blueprints and Node-RED subflows.
